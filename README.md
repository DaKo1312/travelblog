<b>TravelBlog</b>

Ein moderner und einfacher TravelBlog, der im Rahmen einer Gruppenarbeit während einer Weiterbildung entwickelt wurde.
Das Projekt dient dazu, Reiseziele, Erfahrungen und Eindrücke übersichtlich und ansprechend darzustellen.

➡️ Projektbeschreibung
  - Der TravelBlog wurde mit HTML und CSS entwickelt und legt den Fokus auf ein klares Design sowie eine benutzerfreundliche Darstellung von Reiseinhalten.
  - Im Rahmen der Gruppenarbeit übernahm ich die komplette Organisation des Projekts sowie die vollständige technische Umsetzung und Programmierung.

➡️ Verwendete Technologien
  - HTML
  - CSS
    
➡️ Features
  - Modernes und übersichtliches Design
  - Strukturierte Darstellung von Reisebeiträgen
  - Responsive Layout-Grundlagen
  - Einfache Navigation
  - Saubere und verständliche Code-Struktur
